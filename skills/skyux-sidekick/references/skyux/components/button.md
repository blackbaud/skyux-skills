# Buttons

Buttons trigger actions from within an interface. Choose the documentation that matches how your project creates buttons.

Button classes

The button classes create buttons from plain HTML elements with CSS classes from the @skyux/theme package.

Button component (preview)

The button component creates buttons with the @skyux/forms package.
