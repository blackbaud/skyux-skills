# Charts (preview)

The chart components are currently in preview mode and aren't fully implemented or documented. We plan to finish development of some of these components and officially release them in SKY UX v15.

Charts visualize data in SKY UX applications to help users compare values and spot trends. Select a chart type below to explore its documentation.

- [Bar chart (preview)](./chart-bar.md) - Bar charts provide a simple, declarative way to visualize categorical data.
