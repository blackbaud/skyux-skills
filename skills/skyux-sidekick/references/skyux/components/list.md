# List (deprecated)

Lists display data in a consistent, flexible way.

Lists and their features are deprecated in favor of [data manager](./data-manager.md) and an appropriate view such as [data grid](./data-grid.md) or [repeater](./repeater.md). For more information, see the [list deprecation instructions](../learn/develop/deprecation/list.md).

- [List overview (deprecated)](./list-overview.md) - The deprecated list component displays a SKY UX-themed list of data in a consistent, flexible way.
- [List filters (deprecated)](./list-filters.md) - The deprecated list filters module provides components that allow users to select filter criteria.
- [List paging (deprecated)](./list-paging.md) - The deprecated list paging component displays a SKY UX-themed pagination control for a list.
- [List toolbar (deprecated)](./list-toolbar.md) - The deprecated list toolbar component displays a SKY UX-themed toolbar for a list.
- [List view checklist (deprecated)](./list-view-checklist.md) - The deprecated list view checklist component builds a filterable checkbox list of data.
- [List view grid (deprecated)](./list-view-grid.md) - The deprecated list view grid component provides a SKY UX-themed grid for a list of data.
