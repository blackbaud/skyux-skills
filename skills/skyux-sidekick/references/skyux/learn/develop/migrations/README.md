# Migration

As SKY UX evolves, so do coding patterns and preferences. To take advantage of the latest and greatest that SKY UX has to offer, we recommend that you migrate your projects to align with our current best practices.

Our migration guides help you update your projects to use the latest SKY UX features and patterns. Migrations help ensure your projects stay current with SKY UX, but they are typically optional, unlike [deprecated features](../deprecation/README.md) that are planned for removal in a future major release.

## Migration guides

Convert to standalone

Replace NgModule declarations with standalone components and directives.

Linting --fix

Verify and automatically fix code to meet best practices.

Deprecated features

Use migration scripts to update deprecated features.

In addition to these SKY UX migrations, Angular also provides [migration guides](https://angular.dev/reference/migrations)

[](https://angular.dev/reference/migrations)

to help you keep your Angular projects up to date.
