# Testing

SKY UX provides custom matchers that assert on accessibility, visibility, styling, text, and resource strings in your unit tests.

Vitest matchers

Extend Vitest's expect with the @skyux-sdk/vitest matchers.

Jasmine matchers (deprecated)

The @skyux-sdk/testing matchers for Karma. Migrate to the Vitest matchers.
