# Guidelines

SKY UX is more than a set of user interface components. Equally important for a consistent experience, it includes guidelines to describe how to apply components and the context for when to use them.

- [Artificial intelligence]() - Internal-only guidance to incorporate AI capabilities into user experiences.
- [Buttons and links](./buttons-links.md) - Describes the contexts in which to use different types of buttons and hyperlinks.
- [Call out information](./call-out-info.md) - SKY UX includes several options to highlight information and draw user attention.
- [Content](./content/README.md) - UI text patterns reinforce design principles to create consistent, recognizable user experiences.
- [Content containers](./content-containers.md) - Describes the contexts in which to use different types of content containers.
- [Error handling](./error-handling.md) - Error handling patterns provide guidance on how to present error messages.
- [Filtering lists](./filtering-lists.md) - Filter patterns provide guidance on how to filter lists in various scenarios.
- [Form design](./form-design.md) - Form design patterns accommodate different scenarios and workflows.
- [Manage data](./managing-records.md) - Data management patterns provide guidance on how to add, edit, and remove records and other items.
- [Page design](./page-layouts/README.md) - Responsive, mobile-first layouts provide flexibility and conform to SKY UX standards.
- [Spot illustrations](./spot-illustrations.md) - Spot illustrations in SKY UX applications help orient users across various experiences.
- [User assistance](./user-assistance.md) - User assistance patterns facilitate access to help documentation and other explanatory content.
