# Containers (preview)

Container classes are in preview and may change before their full release in SKY UX 16.

## Containers

Apply a container class to the element that wraps a section of content. Container classes set the background, border, and text color, and SKY UX components inside the container adjust to match.

Default container

The main container for content and actions on a page.

Heading

Body text

`sky-theme-container-default`

Dimmed container

A container for actions or content that is secondary or supports default containers.

Heading

Body text

`sky-theme-container-dimmed`

Backdrop container

A container behind a canvas, WYSIWYG editor, or preview.

`sky-theme-container-backdrop`

## Prominent containers

A prominent container and the header at its top.

Prominent container

A container for tools that work alongside the main page content.

Body text

`sky-theme-container-prominent`

Prominent container header

The header of a prominent container. Supports text, icons, and borderless icon buttons.

Heading

`sky-theme-container-header-prominent`

## Status containers

Containers that communicate status, such as errors and warnings.

Danger container

A container that communicates an error or danger using the danger status background.

Body text with an inline link

`sky-theme-container-danger`

Info container

A container that communicates information using the info status background.

Body text with an inline link

`sky-theme-container-info`

Success container

A container that communicates success using the success status background.

Body text with an inline link

`sky-theme-container-success`

Warning container

A container that communicates a warning using the warning status background.

Body text with an inline link

`sky-theme-container-warning`
