# Design

SKY UX components are assembled from a small set of core design elements. These design elements act as the building blocks for components and allow you to build user interfaces that incorporate SKY UX styles and patterns.

- [Principles](./principles.md) - Learn about SKY UX's design principles.
- [Guidelines](./guidelines/README.md) - Instructions on how to consistently design for specific scenarios.
- [Styles](./styles/README.md) - Core design elements that provide the building blocks for SKY UX components.
